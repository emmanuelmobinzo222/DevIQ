# RideShare - Travel Together, Save Together

![RideShare Logo](https://via.placeholder.com/150x150.png?text=RideShare)

A modern ride-sharing platform that allows passengers to split fares and save money while traveling in the same direction. Built with React, FastAPI, and MongoDB.

## 🌟 Features

### Core Functionality
- **Fare Splitting**: Automatically split ride costs among passengers traveling in the same direction
- **Multi-User Types**: Support for riders, drivers, and parents (for school kids)
- **School Rides**: Dedicated system for school children with parent management
- **Real-time Matching**: Find rides instantly based on location and destination
- **Multiple Ride Options**: 
  - School Kids
  - Private (1 rider)
  - Shared (2-5+ riders)
  - Split Cost

### Security & Verification
- **100% Verified Users**: All users verified through:
  - National ID number
  - Photo of ID document
  - Selfie holding ID
  - Credit card verification
- **Card-Only Platform**: Secure payment processing
- **Multi-Country Support**: Automatic currency detection and conversion
- **Location-Based**: Automatic country detection

### Payment System
- **Automatic Commission Split**:
  - 40% to Creator (Mwenge Emmanuel Mobinzo)
  - 60% to Driver
- **Scheduled Payouts**: Driver payments every Tuesday
- **Multi-Currency Support**: ZAR, USD, EUR, NGN, KES, and more
- **Payment Gateways**: Stripe, PayStack, Flutterwave ready

### User Experience
- **Dark/Light Theme**: Purple-themed UI with automatic theme switching
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Progressive Web App (PWA)**: Install on mobile devices
- **Real-time Updates**: Live ride availability
- **Rating System**: Rate drivers and riders
- **Ride History**: Track all rides and savings
